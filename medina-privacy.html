Privacy Policy

Medina Channel Manager — last updated 19 August 2026

What this application is

Medina Channel Manager is a private, single-user tool. It runs on one person's personal computer and is used by its owner to manage their own YouTube channels — listing videos, reading comments, viewing analytics, and uploading or editing their own content. It is not offered to, sold to, or usable by anyone else.

What data it accesses

When the owner authorises the application through Google Sign-In, it receives an access token for the owner's own YouTube channel. Using that token it may read and manage:

  • the owner's channel details, video list, titles, descriptions and tags;
  • comments on the owner's own videos;
  • playlists belonging to the owner;
  • YouTube Analytics reports for the owner's own channel.

What it does with that data

The data is shown to the owner and used to manage their own channels. It is not analysed for any other purpose, profiled, sold, rented, shared, or transmitted to any third party. There is no advertising, no tracking, and no analytics service involved.

Where data is stored

Access and refresh tokens are stored in files on the owner's own computer. Video files remain on that computer and are transmitted only to YouTube, directly, when the owner chooses to upload one. No server, database or cloud service operated by this application holds any data, because this application has no server.

Google user data

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is never used for advertising, never sold, and never transferred except as required to provide the tool's function to its owner.

Data of other people

This application does not collect, request, or store data about any person other than its owner. Comments written by viewers on the owner's videos are read through YouTube's API and are not retained separately.

Retention and deletion

Tokens remain on the owner's computer until they expire or are deleted. The owner can revoke the application's access at any time at myaccount.google.com/permissions, and can delete the stored token files at any time. Doing either ends all access immediately.

Children

This application is not directed at children.
