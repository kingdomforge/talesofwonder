Privacy Policy

Tales of Wonder Publisher — last updated 11 August 2026

What this application is

Tales of Wonder Publisher is a private, single-user tool. It runs on one person's personal computer and is used by its owner to upload their own gameplay videos to their own TikTok account as drafts, which they then edit and post from within the TikTok app. It is not offered to, sold to, or usable by anyone else.

What data it accesses

When the owner authorises the application through TikTok Login, it receives an access token for the owner's own TikTok account. Using that token it may read:

  • basic profile information (open ID, display name, avatar);
  • profile details such as bio and verification status;
  • account statistics such as follower, following, like and video counts;
  • a list of the owner's own public videos.

It also uploads video files that the owner supplies from their own computer.

What it does with that data

The data is shown to the owner and used to confirm that uploads reached the correct account. It is not analysed, profiled, sold, rented, shared, or transmitted to any third party. There is no advertising, no tracking and no analytics service involved.

Where data is stored

Access tokens are stored in a single file on the owner's own computer. Video files remain on that computer and are transmitted only to TikTok, directly, when the owner chooses to upload one. No server, database or cloud service operated by this application holds any data, because this application has no server.

Data of other people

This application does not collect, request, or store data about any person other than its owner. It has no users other than its owner.

Retention and deletion

Tokens remain on the owner's computer until they expire or are deleted. The owner can revoke the application's access at any time from TikTok's own settings, under Security and permissions, and can delete the stored token file at any time. Doing either ends all access immediately.

Children

This application is not directed at children and is not used to publish content directed at children.
